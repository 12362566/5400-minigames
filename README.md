# 5400小游戏

一个持续扩充的浏览器小游戏合集。

## 游戏列表

### 爆裂城堡 · 倍率炮战（V5）

路径：[games/multiplier-siege/](games/multiplier-siege/)

- 通过倍率门让火箭分裂，破坏地形和城堡支撑。
- 九城远征、无尽围城、首领连战、七分钟突围、经典炮战、自由试炮。
- 12张升级卡、4类普通敌人、2类首领与可破坏弱点模块。
- 5张不同机制地图：峡湾、风沙、高山熔岩、低重力月面、浮岩丛林。
- 实心弹无限；6种特殊弹使用本局库存，从补给箱、敌方模块和战后奖励补充。

## 本地运行

不需要安装前端依赖。进入仓库目录后运行：

```sh
python3 -m http.server 8000
```

打开 http://localhost:8000/ 即可进入合集首页。

这是纯静态网站，可以部署到支持静态文件的托管服务。此仓库暂不自动启用任何托管服务。

## 操作

- 触屏/鼠标：上下拖动战场调角度，左右拖动调力度；松手不会自动开火。
- 底部滑块可精确调整。选择弹种后点击开火。
- 键盘：左右方向键调角度，空格开火，P 暂停。
- 设置菜单切换模式或选择练习地图；构筑菜单查看本局升级。
- 一发主弹消耗一发特殊弹；倍率分裂不额外扣弹。库存跨关保留，重新出征重置。

## 添加其他小游戏

1. 在 `games/` 下新建独立目录。
2. 保持每个游戏有自己的 `index.html` 与所需静态资源。
3. 在根目录 `index.html` 增加入口，并在本 README 记录玩法与操作。

## 实现与范围

使用原生 HTML、CSS 和 JavaScript Canvas，无第三方运行时依赖。高分只保存在当前浏览器。

这是一款独立实现并扩展玩法的炮战游戏，参考视频：https://www.bilibili.com/video/BV1dLG66qEMk/ 。不是原作素材包，也未声明与原作者或官方存在关联。

游戏规则已有模拟测试，手机适配仍需持续实机测试和难度调校。

## 占格之战 · 多方争霸

路径：[games/grid-capture/](games/grid-capture/)

支持 1v1、三方混战、四国争霸，分别对抗 1、2、3 个独立 AI 阵营。四种地图包含种子随机地图；经营金矿与兵营、争夺中立金库和训练据点，并升级采矿、训练、护甲三项两级科技。手机可点同一地块两次建造，也可使用建造按钮。支持暂停、倍速、难度和种子重开。

这是本地人机游戏，无网络联机。地图与数值采用独立平衡设置，不保证与原作一致。详见游戏内说明和游戏目录 README。
