# 参考观察与复刻范围

参考：[GTT-20260920-3D打砖块-类原生-混剪-17](https://www.bilibili.com/video/BV1dKaq61EXB/)

于 2026-10-13 在浏览器中查看视频实际画面，核对约 00:01、00:07、00:29、00:37、00:52 和 00:58 的内容。原视频是一分钟广告混剪，并非完整游戏教学。

## 已观察到

- 固定的俯视斜角，彩色小方块组成大型立体结构。
- 开头一段有四列后备炮台和五个发射位置。
- 玩家点选队列前方炮台，将其派入发射位；不需要控制挡板或瞄准反弹角度。
- 同色炮台持续自动发射，炮台上的数字随着射击减少。
- 射击沿结构前方逐步打开通道。某颜色被其他颜色挡住时，该炮台会等待。
- 弹药耗尽后发射位空出，后方仍有多个同色炮台待命。
- 后半段换了另一套颜色与立体结构；没有显示完整的胜利、失败或关卡选择流程。

## 为可玩版本补全的规则

这些规则是独立设计，不能声称原视频逐一证实：

- 每个体素需要一次同色命中。原视频无法可靠读出每块的耐久值。
- 每个横向/高度射线只允许命中最前方体素；发射时立即确认命中，飞行轨迹仅作表现，避免穿透或重复计算。
- 五个发射位全部被挡住且无人能够命中时失败，可以立即重开。
- 原创的十二个有限关卡、解锁、断点保存、暂停、音效、轻动效与键盘操作。
- 四列炮台每种颜色的总弹药严格等于该颜色的总方块数。

## 资产与实现

全部体素几何、炮台 SVG、界面、音效均独立生成。未拷贝视频音乐、图片、商标、广告文案或角色素材。2.0 改用 Babylon.js 9.30.0 真正的 WebGL 3D 引擎，独立生成倒角体素、炮台和弹丸实体，统一世界空间并提供实时光照、阴影。固定相机，不声称使用原作引擎。

2026-10-13 再次对照片头绿墙和后半段黄墙，发现混剪有不同视角。片头估测约 14° 方位/46° 仰角；后半段约 32°/32°。默认复刻片头，菜单可切换斜侧视角。边线近似平行，因此采用正交投影；原作精确镜头参数无法由片段确认。首关按片头的宽屋顶/较矮正面比例采用 18×8×16 体素体量，后续包含 14–16 层高墙体；不复制原画面图案。
