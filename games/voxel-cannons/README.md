# 方块炮手 · CUBE SALVO

一款根据视频实际玩法独立制作的离线浏览器小游戏：四列彩色炮台、五个发射位置、逐层清空立体方块。

## 直接玩

解压后双击 `index.html`。无需安装依赖、启动服务或联网；现代 Chrome、Edge、Firefox、Safari 均可使用所需标准浏览器 API。浏览器是否允许本地文件保存进度取决于其设置；如保存不可用，游戏会提示。

## 操作

- 点击下方四列中的炮台，派入第一个空闲发射位。
- 炮台自动消除当前前方露出的同色方块，弹药用完后空出位置。
- 先看外层颜色，避免把五个位置全部留给暂时打不到的颜色。
- 清空雕塑过关。共十二关，通关后解锁下一关。
- 右上角菜单可暂停、继续、重开、选关、切换音效及轻动效。
- 键盘 1–4 选择炮台；空格暂停/继续；Esc 菜单；R 请求重开。
- 进度自动保存在当前浏览器。重新打开有进行中的射击时会先暂停。

## 开发

- `src/levels.js`：十二关体素与弹药队列。
- `src/engine.js`：确定性射击与严格存档校验，无 DOM 或第三方依赖。
- `src/renderer.js`：三维坐标的 Canvas 投影、炮台图形和特效。
- `src/app.js`：交互、菜单、存档和关卡流程。
- `node build.mjs`：将源模块打成支持本地直接打开的 `game.js`。
- `npm test`：引擎与静态回归测试。
- `npm run serve`：可选本地 HTTP 服务。
- `qa/viewport.html`：实际游戏同源 iframe 尺寸与交互回归页面。`?w=320&h=568&auto=1` 可自动运行。

测试路由 `?qa=1` 使用独立内存状态，不读写正常玩家存档。没有统计、广告、跟踪、外部脚本或网络游戏请求。
