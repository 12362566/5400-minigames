# 玩法观察与适配边界

参考来源：用户指定 https://b23.tv/sphgggO ，实际解析为 https://www.bilibili.com/video/BV1XWeg6KEgk/ 。视频标题《你梭不过我你信吗？》，作者解说刘大大，页面标注 2026-09-17。已在浏览器中实际观看并抽查各段画面；视频截图、音频和原游戏资产均未放入本项目。

## 直接观察

- 约 0:08：原游戏标题为《俱乐大玩家》。
- 约 0:31–0:39：四位竞拍者，界面显示“第 1/5 轮”，仓库为不规则大小拍品占据的格子；可见公开轮廓与私人完整拍品信息；能查看已知最低价值与 R1–R5 历史。
- 约 1:05：第二轮，可看到其他人的上轮出价。
- 约 1:25：工具界面展示品质估价类信息工具。
- 约 1:43–1:53：统一开标排序；后续报价可比前轮低，不是只增不减的公开举牌。
- 约 1:58：第五轮，数字键盘输入报价；约 2:03 出现竞拍成功；约 2:20 仓内全部拍品逐一揭晓，显示总价值、成交价、盈亏。
- 约 2:38：再次开局；后段出现不同场景、角色和倍率。
- 约 3:51：输入框说明可读到报价高于第二名的 1.4 倍可直接成交。
- 约 4:22：成交价 700,000，比另一人 699,999 高 1，也可在最终结算中胜出。

## 本作保留的核心

隐藏仓库 + 公开/私人线索 + 密封报价 + 开标历史 + 至多五轮 + 1.4 倍提前成交 + 最终最高价得仓 + 揭宝与盈亏。胜者按自己的报价支付，未中标者不付报价。

## 明确属于浏览器适配/原创设计

- 原创标题、三种角色名称与具体能力、60 种虚构藏品和 SVG、所有数值与概率；不声称这些是原作完整数据。
- 一局固定五仓、120 万初始虚拟币、8×8 仓库、每仓 12–18 件，用于形成完整可重玩单机循环。
- 公共信息每轮增加两件；本作所有 AI 在玩家提交前锁定其报价，只使用自身可见线索和公开历史。
- 1.4 判定按界面“高于”的文字采用严格大于，使用整数交叉相乘避免浮点临界误差。
- 视频不足以确认同价、最终全零和存档规则。本作明确选择种子随机同价抽签、全零流拍、动作重放存档。
- 视频中倍率、联机、角色获取、商业界面不在本作复现范围。无真钱系统，不接外部账号。
- 移除限时压力；新增免费价格图鉴、帮助、全余额报价确认与自动保存，保证手机上可读、可理解、可完成。
