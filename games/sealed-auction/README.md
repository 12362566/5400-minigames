# 暗标拍卖局

原创离线浏览器盲拍小游戏，参考用户提供的《你梭不过我你信吗？》中《俱乐大玩家》的可见核心规则。原视频：[BV1XWeg6KEgk](https://www.bilibili.com/video/BV1XWeg6KEgk/)。本项目与原作无关联，不复制原作人物、美术、音乐或商业系统。

## 游玩

打开 `index.html`（通过 HTTP/HTTPS 静态服务器），选择身份后入场。无需安装依赖或构建。桌面和手机均可操作。

- 四位竞拍者：你与三位拥有独立信息、估值和资金的 AI。
- 一仓最多五轮，密封提交报价后统一开标。下一轮可升价、降价或报 0 暂不跟。
- 最高价严格超过第二名的 1.4 倍时提前成交，否则第五轮最高价得整仓。
- 同价使用可复现的随机抽签；最终全员 0 报价则流拍。
- 只有中标者支付报价。整仓藏品自动变现，差价计入余额。
- 公开轮廓、品质与私人鉴定形成信息差。点物品看详情，点免费图鉴学习估值。
- 两种鉴定工具每仓各一次，费用立即扣除，未中标也不退。
- 一局五仓，初始 120 万虚拟币，争取正收益。完成后可以回看末仓或换身份重玩。
- 全余额报价需要再次确认。没有实时倒计时，不需要抢操作。

所有货币仅供本地单机玩法使用，无充值、支付、提现、兑换或外部交易。

## 存档与实现

使用浏览器本地 `localStorage` 保存种子、身份和合法操作记录；恢复时重放引擎验证，不直接信任任意余额或仓库对象。动作后自动保存，返回入场页可继续。私人浏览模式/浏览器限制存储时会明确显示不能保存。清除浏览器数据会清除进度；不同设备不自动同步。本地存档不是防作弊安全边界。

运行文件：`index.html`、`style.css`、`app.js`、`art.js`、`engine.js`，无外部字体、图片、网络请求或第三方代码。只有合集链接及规则中的参考视频链接离开本页。音效默认关闭，打开后使用本地合成音。

`art.js` 中全部藏品及人物为原创 SVG。仓库 8×8；12–18 件矩形藏品互不重叠。布局在 700px 以下显式变为单列，长历史数值缩写显示，完整数值在标题属性中。

## 验证

```sh
node --test engine.test.mjs
node --check app.js
node --check art.js
node --check engine.js
```

引擎测试无需 npm 包。测试使用 Node 内置测试运行器（Node 18+；Node 24 可直接加载运行文件）。

`tests/mobile-preview.html` 使用真实同源 iframe 提供 320/390/410 CSS 像素宽度，避免仅改变外层截图大小。打开后选宽度，完成正常操作，点“检查布局”检查实际文档宽度与网格列数。

规则证据与适配边界见 `REFERENCE.md`；测试范围见 `QA.md`；完整引擎 API 见 `ENGINE.md`。
