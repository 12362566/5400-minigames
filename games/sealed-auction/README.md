# 暗标拍卖局

原创离线浏览器盲拍小游戏，参考用户提供的《你梭不过我你信吗？》中《俱乐大玩家》的可见核心规则。原视频：[BV1XWeg6KEgk](https://www.bilibili.com/video/BV1XWeg6KEgk/)。本项目与原作无关联，不复制原作人物、美术、音乐或商业系统。

## 游玩

打开 `index.html`（通过 HTTP/HTTPS 静态服务器），选择身份后入场。无需安装依赖或构建。桌面和手机均可操作。

## 1.2 一屏快捷出价

对局主画面固定在当前可见屏幕内：仓库、轮次、余额、报价草稿和提交无需上下滚动。右侧“情报 / 鉴定 / 记录 / 图鉴 / 设置”打开侧栏；长内容只在侧栏内部滚动。主画面直接显示常用金额与加减按钮，只改草稿，仍需明确提交。

初始余额下可直接点10万、30万、50万，或使用±1万/±5万。“上次”填入你自己上一轮的报价，不是对手最高价。低余额时按钮面额按十进位缩小，超过余额的预设不可用，加减限制在0与余额之间。主画面同时显示完整整数和“万”单位，数值按钮不是估价建议。

平时不用键盘。需要任意整数时点“精确”，在弹窗填入后回到主画面确认出价；取消不修改草稿。“全部余额”也只填入，实际提交仍需全余额确认。

仓库根据可用宽高等比缩放，使用 `visualViewport` 与尺寸观察器适应窗口、横竖屏和键盘引起的可视高度变化。侧边按钮至少44×44 CSS像素；紧凑横屏把侧边工具排列为两列，并将仓库与快捷报价区左右并排。真实手机键盘与安全区仍需设备验证，不能用桌面缩小视口代替。

本次只改界面，`engine.js`、`art.js`、全部竞拍规则、AI信息边界和原存档键保持不变，旧存档可继续。

- 四位竞拍者：你与三位拥有独立信息、估值和资金的 AI。
- 一仓最多五轮，密封提交报价后统一开标。下一轮可升价、降价或报 0 暂不跟。
- 最高价严格超过第二名的 1.4 倍时提前成交，否则第五轮最高价得整仓。
- 同价使用可复现的随机抽签；最终全员 0 报价则流拍。
- 只有中标者支付报价。整仓藏品自动变现，差价计入余额。
- 公开轮廓、品质与私人鉴定形成信息差。点物品看详情，点免费图鉴学习估值。
- 两种鉴定工具每仓各一次，费用立即扣除，未中标也不退。
- 一局五仓，初始 120 万虚拟币，争取正收益。完成后可以回看末仓或换身份重玩。
- 全余额报价需要再次确认。没有实时倒计时，不需要抢操作。

所有货币仅供本地单机玩法使用，无充值、支付、提现、兑换或外部交易。

## 存档与实现

使用浏览器本地 `localStorage` 保存种子、身份和合法操作记录；恢复时重放引擎验证，不直接信任任意余额或仓库对象。动作后自动保存，返回入场页可继续。私人浏览模式/浏览器限制存储时会明确显示不能保存。清除浏览器数据会清除进度；不同设备不自动同步。本地存档不是防作弊安全边界。

运行文件：`index.html`、`style.css`、`screen.css`、`app.js`、`art.js`、`engine.js`，无外部字体、图片、网络请求或第三方代码。只有合集链接及规则中的参考视频链接离开本页。音效默认关闭，打开后使用本地合成音。

`art.js` 中全部藏品及人物为原创 SVG。仓库 8×8；12–18 件矩形藏品互不重叠。一屏主布局显式定义主区域和侧边工具列，不继承旧双列信息面板。历史数值在侧栏内缩写显示，完整数值在标题属性中。
