# 旋刃守卫 · 五章远征

原创中文、移动端优先的单机浏览器塔防。部署旋刃英雄、击破宝蛋、合成升级，再用天赋、元素反应和组合技能构筑一支远征队。

静态入口：`index.html`。没有构建步骤、外部运行依赖、账户或服务器存档。请通过静态 HTTP 服务打开，避免 `file://` 的 ES Modules 限制。

## 2.0：完整长局肉鸽

- **五章三十波**：每章六波，逐渐引入新的威胁。经典八波保留为短局；旧版八波远征存档也可以原样继续。
- **四职业、六阶英雄、十二个部署位**：物理旋刃接触、宝蛋孵化与同种同级合成仍是核心。战斗中可以招募、移动和合成。
- **十四种三阶天赋**：六种通用天赋，以及四职业各两条互斥专精。每清一波提升远征等级并获得天赋点，商店、事件和营地也能提供训练机会。
- **二十四种三阶祝福**：灼烧、减速、破甲、连锁、经济、孵化、生存、主动战技和组合技等方向，能够重复升阶。
- **六种双职业反应**：熔刃、碎冰、磁裂、蒸汽冲击、超载、寒链。印记窗口、反应共用冷却和非递归触发，均在真实战斗中生效。
- **六种组合技、两个装备槽**：对应的两个职业曾达到三级即可解锁。组合在武器接触时触发，各自有冷却，装备取舍会改变构筑。
- **三种主动战技**：集结战吼、极寒脉冲、生命祷言。战斗间歇选择技能，战斗中把握时机使用。
- **十一类敌人与五位机制首领**：包含治疗、护盾、干扰、残血狂暴和窃能。首领有两秒预警、半血阶段变化，以及召唤、护盾、范围压制、汲能与终局轮转。
- **三种风险收益路线、八种事件、六类商店商品、营地选择**：成本、收益和反制方法提前可见。商店显示具体随机遗物和英雄，记录售出状态。
- **满阵也能成长**：准备阶段可付费「营地晋升」，支付同级伙伴价格加 25% 省位费，保留位置升一级。免费合成仍然保留，晋升最高六级。

更多设计说明见 [DESIGN.md](DESIGN.md)，全部验证范围见 [QA.md](QA.md)。

## 时长与节奏

目标是正常一倍速、包含布阵和构筑思考的一小时左右远征，设计范围为 **45–75 分钟**。每波有三至四批连续增援，三十波的标准生成预算合计四十二分钟；敌人被消灭的时刻还受站位和构筑影响。该预算不是用血量硬拖时长，也不等于真人实测。

最终五组常规合法资源模拟的战斗时间为 **43.72–47.17 分钟**；另加8–15分钟构筑思考是设计估计，没有真人计时验证。全部提前援军的对照组为 **15.81 分钟**。完整结果记录在 QA 和 `tests/balance-results.json`。菜单思考、暂停和操作时间不在引擎的战斗计时里，不能混为一谈。

强构筑可以在场上敌人较少时提前召来下一批，承担瞬间压力并获得金币，显著缩短一局。二倍速也会缩短现实用时。因此「一小时」是常规节奏目标，不是每一种玩法的强制最低时间。

## 如何开始

1. 选择下方职业，再点道路旁的亮色草地部署。放在弯道附近，旋转武器更容易接触敌人。
2. 点一位守卫，再点同种同级守卫即可合成；「合成预览」可以比较属性并选择保留的位置。
3. 点击波次查看敌人、增援与首领对策，准备好后开波。
4. 用「构筑」查看天赋、祝福、组合和图鉴。专精互斥；组合最多同时装备两个。
5. 满阵且无法合成时，点击守卫详情查看营地晋升费用。晋升只在准备阶段开放。
6. 注意首领读条和红色预警圈。适时移动英雄或使用极寒脉冲，不要只看生命条。

地图为九列十一行；部署不能挡住敌人道路或宝蛋轨道。回收返还已投入金币的 65%。金色 ↑ 标记可合成伙伴。暂停、倍速、静音和减少动态效果均可使用。

## 存档与兼容

自动存档只存在当前浏览器的 localStorage。清除数据、换浏览器或使用隐私模式可能丢失进度。游戏不上传记录，也不会在关闭后离线自动推进。

- v1 经典/旧远征继续使用原始八波引擎；新五章远征使用独立 v2 引擎。
- 战斗、选择奖励、路线、事件、营地和商店的状态都可恢复；已购买商品不会再次赠送。
- 恢复战斗后先暂停，等待玩家明确继续。
- 读取失败时保留原始数据，明确提醒，不用新局静默覆盖。
- 新旅程会替换当前存档，需要确认。

## 参考与原创边界

本作的职业、地图、数值、流程、专精、祝福、组合、元素反应、首领、商店与事件均为原创扩展。不声称复制未知原作；未采用广告中的进化失败降级。全部画面为 SVG/Canvas 代码原创绘制，音效为程序生成，没有使用视频截图、原游戏精灵或原音频。
