# 旋刃守卫 · 林间远征

原创中文、移动端优先的单机浏览器塔防。静态入口为 `index.html`，无构建步骤、无外部运行依赖、无账户或服务端数据。建议通过静态 HTTP 服务打开，避免浏览器对 file:// ES Modules 的限制。

## 1.2 手机布局修复

- 修复手机仍继承桌面双列网格的问题：战场现在独占第一行，招募、详情与开始按钮位于下一行，战场填满可用高度。
- 窄屏标题和底部状态不再挤压布局；保留顶部、左右与底部安全区处理和 9:11 画布比例。
- 入口使用版本化资源地址以刷新旧缓存，并声明浅色界面。浏览器强制深色功能仍可能覆盖网站颜色。
- 新增 CSS 级联回归检查及 `tests/mobile-preview.html` 窄视口检验页。后者加载正式游戏，供实际浏览器检查；不模拟物理手机、触屏或刘海。
- 引擎、玩法数值与存档格式不变。

## 1.1 优化

- 波次按钮现在可查看准确的敌人构成、首领数、普通敌人生命与应对建议；预览和实际刷怪共用同一套生成逻辑。
- 选中英雄后以金色 ↑ 标记可合成伙伴；新增大点击区域的合成预览，可查看升级前后伤害/旋刃/范围，并选择保留位置。
- 手机小屏也能使用独立的合成按钮；顶部刘海、左右安全区与底部手势条计入固定视口布局；增加返回小游戏合集入口。
- 画面按稳定 30fps 绘制，战斗仍采用原来的 60Hz 固定步长；减少重复 DOM 更新和格子查找，后台停止无效绘制。
- 读取战斗中的存档后先暂停，等待玩家明确继续。存档格式与原版本兼容，关卡数值及平衡不变。

## 玩法

- 草地格子部署英雄，自动旋转的武器通过真实扫掠接触命中道路敌人和宝蛋。
- 点选英雄，再点同种同级英雄，必定合成升级；最高 6 级，同时在场最多 12 位。点空地可移动。
- 旋刃、火焰、冰霜、雷电四种职业：近身输出、范围灼烧、减速、连锁。
- 宝蛋孵出一级英雄；弯道与蛋道旁的站位有不同收益。
- 经典守关：固定路线、完整八波。林间远征：八波、八种祝福池（每局三次三选一）、三个地图与两次路线决策。
- 包含普通敌人、快跑敌人、护甲敌人、分裂敌人及首领，首领出现在第 4、8 波。
- 暂停、1×/2×、可关闭的轻音效、减少动态效果、部署合法格高亮、同级合成目标高亮、属性详情、回收确认、新旅程确认、本机自动存档。

推荐开局可尝试旋刃卫 (2,2)、旋刃卫 (6,4)、烈焰守卫 (3,9)，坐标为从零起算的列、行。最后一处可覆盖下方道路及宝蛋。游戏不要求这套布局。

## 参考与原创边界

用户给定参考：https://b23.tv/GZxiftV

已核对原始视频：https://www.bilibili.com/video/BV15uaZ6NEHT/

标题为《弹珠一弹，塔防开干！》，是一则约 30 秒广告展示，而非完整规则说明。广告中的商业游戏名称未确认。

可观察到的机制包括：草地网格、曲折道路敌人队列、带生命数字的敌人和宝蛋、绕英雄旋转的近战武器、同级英雄合成、宝蛋产出以及进化奖励选择。未观察到弹珠瞄准发射，因此本作没有把它改造成打砖块式发射游戏。

本作的四职业、数值、经济、完整八波、三张地图、首领与敌人组合、固定成功合成、祝福协同、分支路线和全部操作界面均为原创扩展。未采用广告中的进化失败降级惩罚，也不声称复制未知原作规则。

全部画面由 SVG/Canvas 代码原创绘制，音效为程序生成的短音。未使用视频截图、原游戏精灵、原音频或第三方图片。

## 文件

- `index.html`：语义结构与入口
- `style.css`：桌面布局与固定视口移动端操作面板
- `app.js`：Canvas 渲染、触控、弹窗、音效及本机存档
- `engine.js`：独立、确定性固定步长模拟
- `tests/engine.test.mjs`：引擎与完整通关策略测试
- `tests/ui-smoke.mjs`：DOM/Canvas mock 的 UI 集成冒烟测试，含合成/敌情预览、绘制节流及存档恢复暂停
- `tests/mobile-layout.mjs`：解析实际 CSS 级联的手机布局回归及安全区尺寸计算
- `tests/mobile-preview.html`：发布目录中以真实 iframe 窄视口检验正式游戏的页面
- `QA.md`：验证范围与明确限制

## 检查

```sh
node --check app.js
node --check engine.js
node tests/engine.test.mjs
node tests/ui-smoke.mjs
node tests/mobile-layout.mjs
```

存档只保存在当前浏览器的 localStorage。清理数据、换浏览器或隐私模式可能丢失存档。静态站点不上传游戏记录。
