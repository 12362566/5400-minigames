# 占格之战 · 多方争霸

六角领地即时策略小游戏，无运行时依赖，与合集其他游戏独立。

## 玩法

- 1v1、三方混战、四国争霸：玩家分别对抗 1、2、3 个独立 AI 阵营，AI 之间也会交战。
- 四种地图，包含支持种子的随机地图；可重开同一种子或换种子。
- 建金矿、开兵营、自动出兵，占领领地并攻打敌方主城。
- 争夺中立金库与训练据点，获得本阵营的经济或训练加成。
- 采矿、训练、护甲三项科技，各有两级，仅在本局生效。
- 手机点选地块后，再点同一格或点击建造按钮；电脑也支持方向键、Enter 和空格暂停。
- 支持难度选择、暂停、倍速、重开与操作说明。切到后台自动暂停。

## 运行

从合集根目录启动静态 HTTP 服务，打开 games/grid-capture/index.html。返回合集链接为 ../../index.html。
