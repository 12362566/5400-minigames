# 占格之战 · 触控大地图与多方争霸

无需账号或后端的六角领地即时策略游戏。支持 1v1、三方和四方独立 AI 混战；这是本地人机游戏，没有网络联机。

## 触控操作

- 正常游玩以战场为主，顶部显示金币、收入、时间或发展期与暂停；保留王国、回主城、全图入口。战况、帮助、种子、声音、倍速和返回合集在暂停菜单。
- 单指或鼠标拖动平移局部大格地图。“局部视野”提供缩放和方向按钮，“回主城”快速定位。打开建筑托盘不会把地图重置成全图。
- 点可建设地块打开两行四列的八种建筑卡，点卡片抬手直接购买，成功后收起。原地块提案有标记，盲盒保留默认入口。反复点地图只选地，不会购买。
- 全图为只读总览：点区域回到局部视野，不在小格上花钱。
- 点己方建筑打开专属操作；首次选择分支或路线先预览再确认。锁定分支后的普通升级用带价按钮；路线二级仍明确确认。
- 军械库先显示两种武器。选武器、点目标预览，再单独确认开火；地图点击不发射。面板显示价格、库存、射程和可用状态。
- 卡片和确认按钮在同一指针抬手时执行；拖动、拖出、多指、取消、暂停、旋转、后台和重开会取消旧手势。保留鼠标、键盘和辅助技术点击操作。

## 地图与发展期

- 经典：9×15 格，3 分钟，无发展期。
- 大地图：15×25 格，8 分钟，可选 60 秒发展期。
- 超大地图：21×33 格，12 分钟，可选 90 秒发展期。

发展期可关闭，对所有阵营公平生效：可以建设、积金、升级和训练，停止进军、伤害与占领，结束后统一出征。四类地图与自定种子保留；同图重开保留模式、地图、大小、发展期开关与种子，换种子重开仅改变种子。

## 经营与战斗

保留金矿、步兵营、弓箭营、守卫塔、骑士营、军械库、医馆、战鼓营八种普通建筑，十六个互斥建筑分支、富国/坚城/征战三条两级路线、三种两级科技、中立据点与盲盒。

军械库的范围轰击与穿透炮消耗金币和有限弹药，并有冷却。选目标只预览，确认时重新检查来源、金币、弹药、冷却、射程和发展期；暂停、退出或重开取消瞄准。友军免伤，允许向没有敌人的位置开火并正常消耗资源。

各 AI 有独立经济、军队、路线和升级，执行经营、集结、推进、回防与收缩，并有经营型、扩张型或稳守型风格。暂停战况可查看其风格与当前意图。不会给 AI 额外初始资源或隐藏战斗属性。

主城失守即淘汰；玩家失守立即结算，消灭一方不会提前赢下多方混战。时间到比较存活阵营领地。大地图不提高单位上限。
