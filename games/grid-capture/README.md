# 占格之战

六角领地即时策略小游戏，无运行时依赖。与合集其他游戏独立。

参考视频：https://www.bilibili.com/video/BV1gtjy6DEPj/ （占敌人的格子让敌人无格子可占）

保留视频中可观察到的红黄领地、中央湖泊、相邻付费扩建、金矿、军队自动推进和占地战斗。画面为原创绘制，未复制原作素材。

## 玩法

- 玩家控制下方黄色势力，红方由 AI 控制。
- 点击可扩建的相邻地块，再点击建造。
- 金矿增加收入，步兵营、弓手营、骑士营持续出兵，守卫塔保护路口。
- 军队会绕过湖泊，自动战斗并占领经过的敌方空地。
- 攻破对方主城立即获胜；三分钟结束后比较领地数量，相同则平局。
- 可暂停、倍速、重新开始。切到后台会自动暂停。

本版地图、经济、单位数值、盲盒概率和完整胜负规则是独立平衡设置，视频没有展示足够信息来确认与原作完全一致。没有充值或联网对战。

## 运行与操作

从合集根目录运行静态 HTTP 服务，打开 games/grid-capture/index.html。

手机点选地块；电脑也可以用方向键选择、Enter 建造、空格暂停。主页面提供难度与操作说明。

运行文件：index.html、style.css、engine.js、game.js。引擎逻辑已通过自动化对局和路径/建造/结算检查；真实手机体验仍需持续验证。
